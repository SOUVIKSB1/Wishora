# 🎂 WISHORA — Birthday Wish Experience App

> **Design Directive:** Anti-AI-generated. Hand-crafted, tactile, and opinionated — inspired by CRED's dark-glass premium UI meets iOS fluid physics.

---

## 🌟 Key Features

1. **"Velvet Glass" Design System**
   - Deep Void `#08080C`, Glass surfaces with backdrop blur, Warm Gold `#C8A96E` accents.
   - Adaptive Gender/Age Themes: *Candy World*, *Electric Midnight*, *Rose Dusk*, *Timeless Gold*, *Cosmic Purple*.

2. **6-Step Create Wish Wizard**
   - **Step 1: Recipient Details** — Live name preview card, custom touch wheel date picker, gender selector.
   - **Step 2: AI Wish Message** — Multilingual support across 11 languages (English, Bengali, Hindi, Spanish, French, German, Japanese, etc.), 4 emotional tones (Funny, Heartfelt, Poetic, Short & Sweet), 1-click generation, and character counter.
   - **Step 3: Memory Album & Photos** — Upload up to 12 photos, drag reorder, custom captions, and face spotlight.
   - **Step 4: Soundscape & Trimmer** — Waveform visualizer with draggable start/end handles (0-30s) and preset synthesizers (Orchestral, Lo-fi, Bollywood, Acoustic, Ambient).
   - **Step 5: Visual Atmosphere** — Adaptive theme computation with real-time rendered preview card.
   - **Step 6: Review & Sealing** — Progressive loader phrases, 1-click link copying, and native share intents (WhatsApp, SMS, Email).

3. **7-Screen Recipient Cinematic Experience (`/w/:slug`)**
   - **Screen 1: Wax Sealed Envelope** — 3D gravity physics drop, wax seal with initials, interactive swipe/tap unseal with paper crinkle sound & spring fold.
   - **Screen 2: The Countdown** — Live countdown in giant Clash Display numerals.
   - **Screen 3: Handcrafted Cake & Mic Blow** — Tiered cake with candles flickering using custom canvas flame simulation + real-time microphone air blow detection (amplitude spike) with progressive extinguishing, smoke particles, and confetti blast.
   - **Screen 4: Journey Timeline** — Milestone ribbon from birth year to current year with contextual life moments.
   - **Screen 5: 3D Photo Album** — Blur-to-sharp image reveals, face spotlight, captions in Instrument Serif italic, parallax swiping.
   - **Screen 6: Grand Celebration** — 12 floating helium balloons with spring physics & tap-to-pop confetti, confetti cannons, Ken Burns background zoom, and glowing wish text.
   - **Screen 7: Surprise Reaction** — 15-second webcam/mic video or audio note reaction recorder that auto-saves to sender's Memory Vault + CTA.

4. **Contacts Management & CSV Import**
   - Upcoming birthday countdown badges ("TODAY 🎉", "in 3 days").
   - Smart bulk CSV import with header detection, column mapping, and duplicate conflict resolution (Update / Skip / Duplicate).

5. **My Wishbook & Memory Vault**
   - Folder organization with color badges.
   - Drafts auto-save and resumption.
   - Memory Vault for viewing received reaction videos.

## 🚀 Quick Start

### 1. Start the Backend API Server
```bash
cd backend
npm run dev
# Running at http://localhost:3001
```

### 2. Start the Frontend Development Server
```bash
cd frontend
npm run dev
# Running at http://localhost:5173
```
